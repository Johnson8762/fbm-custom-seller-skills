# 亚马逊关键词库分析器

## 运行环境（box）——数据源替代

| 原数据源 | box 替代 |
|---|---|
| ABA 方法 A 词根拓词 | Sorftime `keyword_extends`（含周/月搜索量、周排名、建议 CPC）、`keyword_detail`；也可用 `amazon-aba-keyword-monitor/` 的 ABA 抓取脚本 |
| ABA 方法 B ASIN 反查 / SIF 反查（相关性 40+） | Sorftime `product_traffic_terms`、`competitor_product_keywords`（无 SIF「相关性得分」，用曝光位置/自然排名近似，须注明） |
| 前台下拉框（AmzChart/插件） | `python amazon-keyword-analyzer/amazon_autocomplete.py "<词根>" [--expand a-z] [--site US|UK|DE|CA] -o ac.json`（无需登录） |
| AMZ123 词频统计 | 词库脚本自动生成「词根词频」sheet |
| 卖家精灵、商机探测器（后台） | **不可用**（需 Seller Central / 付费账号）；用户可导出 CSV 后并入 |
| CPC/竞价 | Sorftime `keyword_detail` / `keyword_extends` 的建议出价 |

- 词库构建：`python amazon-keyword-analyzer/build_keyword_library.py <extends.json> <ac.json> [更多 JSON/CSV] --exclude-roots "free,cheap,..." -o reports/keywords/<产品>/关键词库.xlsx`
  - 自动去重、词根拆分、匹配方式与出价区间（CPC±20%）建议、广告分组（高流量 ≥10k / 中流量 ≥1k / 长尾）；相关性默认「待判断」，**由 AI 按下文分类标准逐词判定**后写回
- 输出目录：`reports/keywords/<产品>/`（Excel + 分类报告 + 投放策略 + 文案建议）
- Sorftime：box 上已接入 Sorftime MCP（`user-sorftime` 命名空间，先 `GetDynamicTools` 看参数再 `CallDynamicTool`）；脚本内调用用 `_shared/sorftime_http.py`（读环境变量 `SORFTIME_KEY`，**绝不打印**）。下文所有 `MCP:工具名` 都指这些 Sorftime 工具。
- 定制产品注意：personalized / custom / engraved / name 等定制修饰词通常为高相关核心属性词

## 核心能力

基于亚马逊运营实战方法论，为产品构建完整的关键词底层资产，支撑广告投放与 Listing 优化。

**输入**：产品核心词根（如 air purifier）+ 竞品 ASIN 列表
**输出**：
- 完整关键词库 Excel（包含相关性分类、搜索量、竞争度）
- 关键词分类报告（高相关/弱相关/无关）
- 广告投放分组策略
- Listing 文案优化建议（标题词根 + 五点描述）

## 工作流程

### 阶段一：词库构建（全局流量捕获）

从三个维度采集关键词，形成基础词库：

#### 1. ABA 热门搜索词（官方风向标）
- **方法 A - 词根拓词**：输入核心词根，拉取所有带排名的同类词根词
- **方法 B - ASIN 反查**：锁定类目 Top 5-10 竞品 ASIN，查看流量词

**数据来源**：亚马逊后台 → 品牌 → 亚马逊品牌分析 → 亚马逊搜索词

#### 2. 前台下拉框（截流用户直觉）
- 在亚马逊前台搜索框输入核心词根
- 收集自动补全的下拉词（包含高转化长尾属性词）
- 可使用插件批量抓取（如 AmzChart、JS 插件）

#### 3. SIF 反查（填补长尾盲区）
- 使用 SIF 插件深度反查核心竞品
- 重点关注**相关性得分 40+** 的词条
- 捕获未进入 ABA 排名的"隐形流量词"

**操作路径**：SIF 插件 → 相似竞品拓词 & 筛查 → 下载数据

#### 4. 合并去重
将以上三路词源合并，去除重复词条，形成**新品基础词库**。

---

### 阶段二：关键词分类（从"海选"到"精选"）

#### 三维度分类法

将词库按相关性分为三类：

**1. 高相关词**
- 定义：搜索结果与产品形态高度契合
- 特征：同款产品类词、核心属性词、主流量词
- 用途：广告投放主战场、Listing 核心词根

**2. 弱相关词**
- 定义：包含关系或属性错配
- 特征：大类词（如 Kitchen Gadgets）、互补产品词、配件词
- 用途：长尾流量补充、场景拓展

**3. 完全无关词**
- 定义：形态完全不同的产品
- 特征：错误匹配、其他品类词
- 处理：直接剔除，加入否定词库

#### 高效筛选技巧

1. **按相关性降序**：优先处理相关性 40+ 的核心词
2. **词根批量判定**：识别无关词根（如 electric、automatic），一键排除
3. **参考 SIF 标准**：利用插件的相关性评分加速判断
4. **从高到低分区间**：或按关键词字母降序判断，提升效率

### 阶段三：实战运用

#### 1. 广告投放：模块化作战

**分组策略**：
- 按**流量区间**分组（高流量词 / 中流量词 / 长尾词）
- 按**使用场景**分组（厨房场景 / 办公场景 / 礼品场景）
- 按**产品属性**分组（材质 / 尺寸 / 功能）

**命名逻辑**（核心）：
```
日期-广告类型-ASIN-匹配方式-竞价策略-属性关键词
示例：2026.04.07-SP-B0TYXXXX-Exact-Up/Down-KitchenTool
```

**投放建议**：
- 优先投放**高相关词**
- 使用批量上传表格（提升效率，便于全局管理）
- 分匹配方式测试（精准 / 词组 / 广泛）

#### 2. 文案优化：词频统计与 AI 排列

**词频分析**：
- 使用 AMZ123 等工具对高相关词进行词频拆解
- 统计高频词根（出现次数最多的词根）
- 将高频词根放入**标题前 50 个字符**

**AI 辅助文案**：
- 提取核心词根列表
- Prompt 示例：
  ```
  利用以下关键词，写一个既符合 SEO 逻辑又具备吸引力的亚马逊五点描述（Bullet Points）：
  [词根列表]
  
  要求：
  1. 每个要点突出一个核心卖点
  2. 自然融入高频词根
  3. 符合亚马逊 Listing 规范
  4. 突出产品差异化优势
  ```

---

### 阶段四：动态维护

关键词库是"活"的，需要持续更新：

#### 月度增量更新
- 每月重新拉取竞品流量词
- 捕捉新崛起的长尾词
- 关注市场趋势变化

#### 广告数据反哺
- 提取广告跑出来的**客户搜索词**（Customer Search Term）
- 这些词是"真金白银"投票出来的，转化率更高
- 将高转化搜索词加入词库

#### 竞争格局监控
- 使用 SIF 多产品对比流量分析
- 按销量最好的 ASIN 降序排列搜索曝光流量
- 分析流量差异，找到优化空间

#### 坑位实时监控
- 每 3 小时监控广告位、自然位坑位
- 下载前 12 小时、48 小时数据
- 分析威胁、流量空挡、优化策略

## 新品关键词优化路径（完整版）

针对新品上架，推荐以下系统化路径：

### Step 1：多产品对比流量分析
- 选取 9-10 个核心竞品 ASIN + 自己的产品 ASIN
- 在 SIF 多产品对比中进行精细化对比
- 按销量最好的 ASIN 和目标竞品 ASIN 降序排列
- 查看自己产品的流量差距

### Step 2：流量拓展
- 选取 20 个竞品 ASIN
- 在卖家精灵「关键词优化 - 拓展流量词」中按畅销变体拓展
- 下载数据，建立关键词追踪表

### Step 3：类目竞品关键词收集
- 用核心关键词在亚马逊前台搜索
- 抓取 50-100 个类目相关竞品
- 使用 SIF 关键词收集功能
- 进行相关性筛查

### Step 4：确定大词
- 在后台商机探测器查看「关键词」份额
- 确定大词有哪些
- 做大词、词根规划

### Step 5：竞争格局分析
- 在 SIF 关键词中查看竞争格局
- 分析自然流量份额分布
- 查看在售产品自然流量分布

### Step 6：CPC 情况分析
- 查看关键词 CPC 情况
- 具体看在哪个类目下（最小节点）
- 评估广告投放成本

### Step 7：ECPM 综合分析
- 关注每天整体链接的点击率、转化率
- 对比广告转化率、自然订单占比
- 结合类目平均转化率、竞品转化率
- 进行纵向对比和横向对比

## 使用示例

**用户输入**：
```
产品：Air Purifier（空气净化器）
竞品 ASIN：B08XXXX, B09YYYY, B0AZZZZ（3-10 个）
```

**执行流程**：
1. 从 ABA 拉取词根拓词数据
2. 模拟前台下拉框采集
3. 使用 SIF 反查竞品流量词
4. 合并去重，形成基础词库
5. 按三维度分类（高相关/弱相关/无关）
6. 词频统计，提取高频词根
7. 生成广告分组策略
8. 输出 Listing 文案建议
9. 打包交付完整关键词资产包

## 注意事项

1. **数据来源真实性**：优先使用亚马逊官方数据（ABA），插件数据作为补充
2. **相关性判断标准**：需结合产品实际形态，不能完全依赖工具评分
3. **动态更新频率**：建议每月更新一次，广告数据实时反哺
4. **广告投放节奏**：新品期优先投放高相关词，稳定期逐步拓展弱相关词
5. **文案合规性**：生成的 Listing 文案需符合亚马逊规范，避免违禁词

## 最佳实践

1. **从核心词根出发**：不要盲目采集，以产品核心搜索词为圆心扩散
2. **竞品选择精准**：选择真正的直接竞品，避免跨品类干扰
3. **分类标准一致**：建立自己的判断逻辑，保持标准一致性
4. **广告数据反哺**：定期提取广告跑出来的客户搜索词，这是最有价值的数据
5. **持续监控优化**：关键词库不是一次性工程，需要持续维护更新

---

**核心理念**：关键词不仅仅是字母的组合，它是消费者的需求图谱。构建关键词库的过程，就是深入理解产品和市场的过程。
