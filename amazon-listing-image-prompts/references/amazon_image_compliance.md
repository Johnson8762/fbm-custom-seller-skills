# 亚马逊产品图片合规指南

> Image-Skill 参考文档。所有生成的图片 Prompt 必须符合以下规范。

---

## 1. 主图（Main Image）硬性要求

| 规则 | 要求 | 违规后果 |
|------|------|---------|
| **背景** | 纯白色 (RGB: 255,255,255 / Hex: #FFFFFF) | Listing 被抑制 |
| **产品占比** | 产品至少占画面 85% | 搜索权重降低 |
| **内容限制** | 仅展示待售商品本身，不含配件（除非包装内含） | Listing 被抑制 |
| **文字/Logo** | 不允许任何文字、Logo、水印 | Listing 被抑制 |
| **边框/插图** | 不允许边框、色块、插图叠加 | 搜索权重降低 |
| **模特（服装类）** | 允许真人模特，不允许人偶/假人模特 | 品类违规 |
| **模特（非服装）** | 不允许出现人物 | Listing 被抑制 |
| **分辨率** | 最长边 ≥ 1600px（推荐 2000px+），启用缩放功能 | 无法启用缩放 |
| **文件格式** | JPEG (.jpg), PNG, TIFF, GIF (非动画) | 上传失败 |
| **文件大小** | ≤ 10MB | 上传失败 |
| **宽高比** | 推荐 1:1 正方形 | 显示不完整 |

### 主图 Prompt 合规检查项

生成主图 Prompt 时，必须包含以下强制指令：
```
- Pure white background (Hex: #FFFFFF)
- No logos, no watermarks, no text overlay
- No props, no decorative elements
- Product only, clean and isolated
- Product occupies at least 85% of the frame
```

---

## 2. 辅图（Secondary Images）规范

| 规则 | 要求 |
|------|------|
| **数量** | 最多 8 张（含主图共 9 张） |
| **背景** | 允许非白色背景、场景图、生活方式图 |
| **文字标注** | 允许信息图（尺寸标注、功能说明）|
| **对比图** | 允许与自家产品对比，**禁止对比竞品** |
| **图表** | 允许使用图表展示技术参数 |
| **多角度** | 允许展示产品不同角度 |
| **使用场景** | 允许展示产品在使用中的状态 |
| **分辨率** | 与主图相同，≥ 1600px |

### 辅图禁止项

- ❌ 竞品品牌名称或 Logo
- ❌ Amazon Logo 或 Prime 标识
- ❌ "Best Seller"、"#1" 等排名声明
- ❌ 促销信息（折扣/价格/优惠码）
- ❌ 裸露/暴力/政治敏感内容
- ❌ 外部网站 URL
- ❌ 客户评论截图（可用 "★★★★★" 风格化展示）

---

## 3. A+ Content 图片规范

### 尺寸要求

| 模块类型 | 推荐尺寸 (px) | 最低分辨率 |
|---------|--------------|-----------|
| Hero Banner (全幅) | 970 × 600 | 970 × 300 |
| 标准图文模块 | 970 × 600 | 300 × 300 |
| 对比表头图 | 150 × 150 | 150 × 150 |
| 四格图 | 220 × 220 | 220 × 220 |

### A+ 合规要求

- ✅ 可使用品牌 Logo（在品牌故事模块）
- ✅ 可使用文字叠加（但需清晰可读）
- ✅ 可使用图表和信息图
- ❌ 不可包含定价信息
- ❌ 不可包含促销/折扣信息
- ❌ 不可包含运费/配送信息
- ❌ 不可包含时效性信息（"2026年最新"）
- ❌ 不可引用 Amazon 客户评论
- ❌ 不可使用 Amazon 商标/Logo

---

## 4. 广告素材规范

### Sponsored Brands 尺寸

| 广告位 | 推荐尺寸 |
|--------|---------|
| Desktop Banner | 1200 × 628 |
| Mobile Banner | 1200 × 628 |
| Video | 1920 × 1080 (16:9) 或 1080 × 1080 (1:1) |

### Sponsored Display 尺寸

| 广告位 | 推荐尺寸 |
|--------|---------|
| 标准广告 | 1200 × 628 |
| 自定义图片 | 1200 × 628 或 600 × 500 |

### 广告素材合规要求

- ✅ 允许包含文字（需在安全区内）
- ✅ 允许使用品牌 Logo
- ❌ 不可使用 Amazon 品牌/Logo
- ❌ 文字不可超出画面安全区（上下左右各留 5% 边距）
- ❌ 不可使用模糊/低质图片
- ❌ 不可包含误导性按钮（如假的 "Play" 按钮）

---

## 5. AI 生成图片政策（2025/2026 更新）

> Amazon 目前**允许使用 AI 生成的产品图片**，但有以下条件：

| 要求 | 说明 |
|------|------|
| **真实性** | AI 图片必须准确反映实际产品的外观 |
| **材质/颜色** | 不得通过 AI 美化产品的真实材质或颜色 |
| **尺寸比例** | 参照物和尺寸比例必须准确 |
| **包装** | 如展示包装，必须与实际包装一致 |
| **功能** | 不得展示产品不具备的功能 |

### Prompt 中的防过度美化指令

生成 Prompt 时，建议加入以下约束：
```
[Realism Constraint]
- Color must accurately represent the actual product color: [具体颜色]
- Texture must match real [material] — no artificial enhancement
- Proportions must be true to actual product dimensions: [尺寸]
- No features that the product does not actually have
```

## 6. 品类特殊规则

### 服装类
- 主图允许使用真人模特（站立全身或上半身）
- 模特不允许坐姿/跪姿/夸张pose
- 推荐使用多种族模特（US 站）
- 主图模特不允许佩戴与产品无关的配饰

### 食品类
- 主图必须展示实际产品或包装正面
- 不允许展示食用场景作为主图
- 营养标签需清晰可读

### 电子类
- 需展示产品真实的接口/按钮布局
- 不允许虚构 UI 界面
- 需准确展示产品尺寸（建议放参照物）

### 珠宝类
- 推荐使用灰色渐变背景突出光泽
- 需展示实际尺寸参照
- 扣件/链条细节需清晰可见
