# 关键词构造指南 — 定制化产品需求验证

在执行 Step 0 时，根据用户输入的品类和定制化方向，构造 5-8 个英文关键词变体。

## 定制化关键词构造模式

| 模式 | 格式 | 示例（品类=dog shirt） |
|------|------|----------------------|
| P1 | `custom [品类]` | custom dog shirt |
| P2 | `personalized [品类]` | personalized dog shirt |
| P3 | `[品类] with [定制方式]` | dog shirt with name |
| P4 | `[定制方式] [品类]` | embroidered dog shirt |
| P5 | `[品类] for [场景]` | dog shirt for birthday |
| P6 | `custom [品类] [材质]` | custom dog shirt cotton |
| P7 | `[品类] [定制描述]` | dog shirt with photo |
| P8 | `[同义词] [品类]` | personalized pet apparel |

**规则**：
- ⛔ 至少构造 **5 个**变体，推荐 **8 个**
- P1 和 P2 是必选（`custom` 和 `personalized` 两个词根都要查）
- P3/P4 根据主要定制方式选择
- P5-P8 按品类灵活选择

## 定制化常用英文表达对照

| 中文 | 推荐英文 | 备注 |
|------|---------|------|
| 定制 | custom, customize, customized | 三个形式都查 |
| 个性化 | personalized, personalised | 美式/英式都查 |
| 印花 | printed, print, sublimation | sublimation 是热升华印花 |
| 刺绣 | embroidered, embroidery | 两个形式都查 |
| 刻字 | engraved, monogrammed | monogram 常见于首饰 |
| 定制尺码 | custom size, made to measure | 服装类必查 |
| 带名字 | with name, name on it | 最常见的定制需求 |
| 带照片 | with photo, photo print | 照片类定制 |

## 补充查询策略

1. **keyword_extends**：对搜索量最高的核心词查延伸词，筛选定制化相关的
2. **Sorftime 推荐词**：检查推荐词中是否有定制化表达
3. **product_search 标题**：从搜索结果标题中提取消费者常用的定制化表述
4. **Amazon Autocomplete**：观察 `custom dog` 后的自动补全建议
