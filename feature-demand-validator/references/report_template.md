# 报告模板 — 定制化需求验证报告

## YAML 头

```yaml
---
created: YYYY-MM-DD HH:MM
topic: [品类] [定制方向] 定制化需求验证
type: 定制化需求验证报告
data_sources: Sorftime MCP / WebSearch / Etsy / TikTok / 1688
data_files: ./YYYY-MM-DD_[品类]_[定制方向]_数据源/
threshold_version: v1.0 — 待校准
---
```

## 写作规则

1. 区分三种标签：`[数据事实]`、`[公开信息]`、`[分析推断]`
2. Review 必须拆分 5 个子维度分别分析，不能笼统汇总
3. 参考维度必须在"风险提示"和"行动建议"中引用，不能只写数据不做交叉验证
4. 排除维度（交付周期）仅记录不判定
5. 结论必须引用具体数值，不允许空泛判断
6. 负面信号必须如实保留
7. 阈值版本号必须标注
