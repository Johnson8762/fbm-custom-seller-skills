# 产品物理规则（做效果图必须遵守）

## 填充异形抱枕（宠物/人形/全家福）
- 填充后的真实变形：**耳朵/四肢/细小突出部分变小变尖，整体轮廓更奇形怪状，印花被填充拉伸**；**绝不会变胖变圆**。
- **无白边款**变形更明显（细部被吃掉），描述必须保留「选无白边会明显变形」提醒；带白边款轮廓更稳。
- 白边宽度按实物：不要画得比实物宽。
- 无白边成品的边缘是图案本身的颜色（如猫毛色），AI 图常出现奶白描边 → 必须去掉（clean_cutout_alpha.py / 重做）。
- 背面：可印文字（名字+生卒年）或同图镜像（人物需非对称姿态才能看出镜像）。是否与正面同价以 facts.json 为准，不要默认加价或默认不加价。
- 尺寸按最长边；10–70 cm 档差距要在图里明显（同一个成人手持对比）。
- 面料以 facts.json 为准（常见示例：荷兰绒 / Dutch velvet + 聚酯填充）。Etsy 材质下拉可能只有 velvet / polyester。

## 平面印花（背心、毯子、抱枕套）
- 平面印花不会变形；颜色以供应商色卡为准；印刷面以确认为准（背心 = 单面）。
- 背心宠物照片印出来是**卡通头像**，不是照片级还原。

## 人物
- 生活场景里抱抱枕的人 = 抱枕上印的人；纪念场景用克制情绪（不哭喊、不夸张）。
- 不出现 3D Hug / 张开双臂造型。
